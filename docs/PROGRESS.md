1. **سجل المستفيد / `BeneficiaryDetailsPage`** (FR-10) — يعتمد على DAO الحملات الموجود فعلياً (`watchCampaignBeneficiaries` بالعكس: حملات مستفيد معيّن)، تكلفة تنفيذ منخفضة نسبياً وقيمة عالية.
2. **البحث والفلترة العامة** (FR-8, FR-9) — يحتاج DAO بحث موحّد جديد عبر `beneficiaries` + JOIN اختياري مع `campaign_beneficiaries`.
3. **لوحة الإحصائيات** (FR-11) — تحتاج `StatisticsDao` جديد + حزمة `fl_chart`.
4. **التنبيهات** (FR-12) — تُبنى فوق استعلامات مشابهة لما في `CampaignsDao` حالياً.
5. **النسخ الاحتياطي** (FR-13) — يحتاج `file_picker` وإدارة دورة حياة اتصال Drift.
6. **التقارير الأربعة المتبقية + `ReportsPage`** (FR-14) — يمكن إعادة استخدام جزء كبير من نمط `CampaignPdfReportGenerator` الحالي.
7. **شاشة الإعدادات** (FR-15 وربط باقي الإعدادات) — تبديل الوضع الليلي يدوياً، حجم الخط، حد التنبيه، شعار الجمعية.
